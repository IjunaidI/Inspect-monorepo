## 1. Problem

`apps/mobile` is code-complete for every ledger row but was built for correctness, not feel:

- one flat expo-router Stack, no tab bar, no persistent chrome — 21 screens reachable only by pushing
  from two ad-hoc header link rows and one `navCard`;
- no font loaded (`expo-font` installed, unused), no icon library (Unicode `‹ ↑ ↓ ✕ →`), no theme layer;
- a 12-colour `palette` with no type/spacing/radius/shadow scale; two competing primitive sheets
  (`components/ui.tsx`, `components/capture/ui.ts`) that had already drifted; 14 files with hardcoded hexes;
- a preset builder that adds blank "Item 01" rows and reorders with ↑/↓ buttons; no library of capture
  points, no garment category anywhere in the schema.

The web console shares the token package but is inline-styled off the old hairline system (~50 files).

## 3. What garment inspections photograph (library seed)

Sources: QIMA pre-shipment inspection guides, Tetra Inspection textile checklist, QC Advisor apparel
checklist, Textile Learner / Designers Nexus points of measure. ~55 global rows in seven categories:

- **OVERALL** — Front flat-lay · Back flat-lay · Left side · Right side · Inside-out front · Inside-out back
- **TOP** — Collar & neckline · Neck hole inside · Left sleeve · Right sleeve · Left cuff · Right cuff ·
  Shoulder seam · Front placket · Chest pocket · Hem · Side seam · Back yoke · Print / embroidery
- **BOTTOM** — Waistband · Belt loops · Fly / zipper top · Zipper open · Fly button · Front left pocket ·
  Front right pocket · Back left pocket · Back right pocket · Coin pocket · Crotch seam · Inseam · Outseam ·
  Leg hem · Rivets & hardware
- **LABELS_TRIMS** — Main label · Size label · Care label · Fibre content label · Country-of-origin label ·
  Hangtag front · Hangtag back · Barcode sticker
- **PACKAGING** — Polybag · Folded presentation · Inner carton · Outer carton · Shipping mark · Carton label
- **TEST** — Measurement setup · Colour vs swatch · Rub test cloth · Button pull · Zipper cycle · Needle
  detector · GSM scale

Each row's `description` is a capture instruction ("Lay flat, collar buttoned, shoot straight down").
Starter templates are pure domain data: *Tops standard 12-shot*, *Bottoms standard 12-shot*, *Labels &
packaging 8-shot*. Points of measure (chest, waist, inseam, rise…) stay on the loop-global measurement
sheet, never as photo slots.

## 4. Data model (INS-097)

```prisma
enum CatalogScope { GLOBAL ORG }                      // renamed from DefectScope; shared
enum CapturePointCategory { OVERALL TOP BOTTOM LABELS_TRIMS PACKAGING TEST OTHER }

model CapturePoint {
  id String @id @default(cuid())
  scope CatalogScope
  orgId String?                 // null = GLOBAL seeded library
  name String
  description String?
  category CapturePointCategory
  iconKey String?               // an IconName; null = the category icon
  referenceImageUrl String?     // storage key under orgs/<orgId>/presets/ (org rows only)
  isArchived Boolean @default(false)
  createdByUserId String?
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt
  organization Organization? @relation(fields: [orgId], references: [id], onDelete: Restrict)
  loopItems PresetLoopItem[]
  @@unique([orgId, name]) @@index([scope]) @@index([orgId]) @@index([category])
  @@map("capture_points")
}
// PresetLoopItem gains: capturePointId String? (onDelete: SetNull, indexed) — lineage only.
```

Migration SQL adds `CREATE UNIQUE INDEX capture_points_global_name_key ON capture_points(name) WHERE
"orgId" IS NULL` and `CHECK ((scope = 'GLOBAL') = ("orgId" IS NULL))`. `buildPresetSnapshot()` and
`InspectionLoopItem` are untouched; a spec pins snapshot item keys to `position, itemName, description,
referenceImageUrl`.

Wire: `CapturePointDto`, `CreateCapturePointInput`, `PresetItemDto.capturePointId?` /
`.capturePoint?: { id, category, iconKey }`, `PresetItemInput.capturePointId?` — all in
`@inspect/shared-types`, registered in `wire-contract.spec.ts`.

Routes (class floor `QA_MANAGER`): `GET /capture-points?q&category&includeArchived`, `POST
/capture-points` (find-or-create; P2002 race converges on the winner; audit `capturePoint.created`),
`DELETE /capture-points/:id` (archive; 404 / foreign or global → 403; audit).

## 6. Mobile architecture (INS-095 / 096 / 098 / 099)

- Root `_layout.tsx`: `SplashScreen.preventAutoHideAsync()`, `useFonts`, `useSessionBoot`,

- Kit `src/components/ui/`: Screen, Header (+BackButton), SectionLabel, SectionHeading, Card, StatCard,
  Grid, ListRow, ListCard, IconTile, Chip, Badge/StatusChip/SeverityBadge, Button, TextButton,
  Field/Input/Textarea/Select, ProgressBar, Sheet, EmptyState/ErrorState, Skeleton, TabBar, Avatar, Icon.

  `custom-point-form`, `item-edit-sheet`, `template-row`.
- Capture (`inspections/[id]/capture.tsx`) is restyled only — zero lines change in `src/lib/`.
